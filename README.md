# DeepCDR in TensorFlow

TensorFlow implementation of DeepCDR for cancer drug-response prediction.

## Context

Built for the Argonne National Laboratory precision-medicine collaboration, so that DeepCDR could serve as one arm of the MEnKF stacker alongside models in the same framework.

## Notebooks

- `Get_Joint_Learner_GDSC_1_Preds.ipynb`
- `Get_Joint_Learner_GDSC_2_Preds.ipynb`
- `Transfer_Learning_on_GDSC_2.ipynb`
- `get_sample_data.ipynb`
- `train_deepcdr_gcn.ipynb`
- `train_deepcdr_gcn_dropout_in_train.ipynb`
- `train_deepcdr_gcn_dropout_in_train_ccle_0.ipynb`
- `train_deepcdr_gcn_dropout_in_train_ctrpv2_0.ipynb`

## Notes on this repository

Notebook outputs are kept intact, so figures and result tables render directly on GitHub. Scheduler logs and trained weights are omitted.

Originally developed during my PhD at the University of Nebraska–Lincoln and previously hosted at `github.com/Ved-Piyush/DeepCDR_TF`.
